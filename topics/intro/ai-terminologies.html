Important AI Terminologies & Keywords

AI has its own language. Understanding these core terms is essential before going deeper into any AI topic — they appear in every textbook, course, and job interview.

1. Data

Data Information used by AI to learn patterns.
AI SystemData Type
Face RecognitionImages of faces
ChatbotText conversations
Voice AssistantAudio recordings
Fraud DetectionTransaction records

Data is the fuel of AI. Without data, AI cannot learn — just as a student cannot learn without study material. YouTube AI learns from watch history, clicks, likes, and search history. All of it is data.

2. Dataset

Dataset A complete, organised collection of data used for training, validating, or testing an AI model.
Analogy

If data = one page of a book, then dataset = the entire book. A dataset might contain millions of labelled images, or millions of text documents.

Dataset TypePurpose
Training DatasetTeach the AI — model learns patterns from this
Validation DatasetTune the AI — used to adjust settings during training
Test DatasetEvaluate the AI — final performance check on unseen data

3. Features

Features The individual measurable characteristics (inputs) that an AI model uses to make predictions.
Example — House Price Prediction

Features: house size, number of rooms, location, parking availability, proximity to schools. Each is one input dimension the model considers.

Fun Example — "Will Aman Eat Pizza Today?"

Features: hunger level, wallet balance, weekday or weekend, smell of nearby pizza. These inputs feed into the prediction model.

4. Labels

Labels The correct answers provided alongside training data, telling the AI what output to expect for each input.
Email (Feature)Label
"Win money now! Click here!"Spam
"Meeting at 5 PM, please confirm"Not Spam

Key distinction: Features = input information. Labels = correct output. During training, the AI learns to map features → labels.

5. Model

Model The trained AI system — the stored result of the learning process, containing all learned patterns.
Analogy

A student studies books → gains knowledge stored in memory. AI studies data → creates a model that stores learned patterns. The model is the AI's "knowledge".

6. Training

Training The process of teaching an AI model using labelled data so it learns patterns and improves its predictions.

During training: the AI makes predictions, calculates how wrong it was, and adjusts its internal parameters to reduce error — repeating this process thousands of times.

Training loop: predict → calculate error → adjust parameters → repeat until performance improves

7. Inference

Inference Using a trained model to make predictions on new, unseen data — the live deployment phase.
TrainingInference
PhaseLearningPrediction
SpeedSlow, resource-heavyFast, lightweight
DataMassive labelled datasetSingle new input
ExampleTraining ChatGPT on internet textChatGPT answering your question

8. Algorithm

Algorithm A step-by-step mathematical method that defines how an AI system learns patterns from data.
AlgorithmCommon Use
Linear RegressionPredicting numbers (e.g. house prices)
Decision TreeClassification (e.g. spam or not spam)
Neural NetworkDeep Learning — images, audio, language

9. Accuracy

Accuracy The percentage of correct predictions made by a model out of all predictions.
Accuracy = Correct Predictions ÷ Total Predictions × 100
Example

AI makes 100 predictions. 90 are correct. Accuracy = 90%.

Warning: High accuracy does NOT always mean a good model. If a dataset has 95% "not spam" emails, predicting "not spam" for everything gives 95% accuracy — but it catches zero spam. Context matters.

10. Bias

Bias Unfair or skewed patterns learned from imbalanced or discriminatory training data.
Example

A hiring AI trained mostly on historically male-dominated industry data may unfairly score female candidates lower — not because they are less qualified, but because the training data contained existing societal bias.

Why Bias Happens

AI learns from human-generated data — and that data already reflects real-world biases, historical inequalities, and human prejudices. The AI inherits and can amplify them.

11. Parameters

Parameters Internal mathematical values (weights) that a model adjusts during training to improve its predictions.
Analogy

Adjusting TV brightness, volume, and contrast to get the perfect picture. During training, AI adjusts millions (or billions) of internal values to minimise prediction error.

12. Epoch

Epoch One complete pass through the entire training dataset.
Example

Dataset contains 1,000 images. AI processes all 1,000 once = 1 epoch completed. Training usually runs for many epochs — each pass the model improves a little.

Multiple epochs: each pass through the full dataset refines the model further

13. Overfitting

Overfitting When a model memorises training data too specifically — performing well on training data but poorly on new, unseen data.
Analogy

A student memorises exact exam questions word-for-word. They score 100% on a repeated test — but fail completely when the questions are rephrased. The knowledge didn't generalise.

14. Underfitting

Underfitting When a model failed to learn adequately — performing poorly on both training data and new data.
Analogy

A student who didn't study at all — they perform badly on both practice tests and the real exam.

15. Neural Network

Neural Network A brain-inspired AI architecture using interconnected layers of artificial neurons — the foundation of Deep Learning.

Input layer → hidden layers → output layer. More layers = deeper network = "Deep Learning"

We will explore neural networks in depth in the Deep Learning section.

16. GPU

GPU Graphics Processing Unit — hardware originally designed for graphics/gaming, now critical for AI training due to its massive parallel computation power.

AI training involves billions of mathematical operations that must run simultaneously. GPUs handle this far faster than CPUs because they contain thousands of small cores designed for parallel processing.

Scale Example

Training a ChatGPT-level model requires thousands of high-end GPUs running for weeks — consuming enormous amounts of electricity and costing hundreds of millions of dollars.

17. Prompt

Prompt The input text or instruction you give to a Generative AI system to guide its output.
Example

Prompt: "Create a futuristic robot image in cyberpunk style with neon lighting." → AI generates the image based on this instruction.

Why it matters: Better prompts → better AI outputs. Prompt Engineering — the skill of writing effective prompts — has become a valued profession in the Generative AI era.

Key Notes

  • Data is the fuel of AI — no data, no learning.
  • Dataset = organised collection; split into training, validation, and test sets.
  • Features are inputs; labels are correct answers.
  • Model = the trained AI storing learned intelligence.
  • Training teaches; inference predicts.
  • Accuracy measures correctness — but can be misleading on imbalanced data.
  • Bias causes unfair AI behaviour — arises from skewed training data.
  • Overfitting = memorisation failure. Underfitting = insufficient learning.
  • GPUs accelerate training by enabling massive parallel computation.
  • Prompt quality directly affects Generative AI output quality.
