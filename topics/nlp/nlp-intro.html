Natural Language Processing — Introduction

Natural Language Processing (NLP) is the branch of AI that gives machines the ability to read, understand, and generate human language. From spam filters to ChatGPT, NLP powers some of the most impactful AI applications today.

💬
Why NLP is Hard
Human language is ambiguous, contextual, and constantly evolving. "I saw the man with the telescope" — did I use the telescope, or did the man have one? Machines must resolve such ambiguity statistically from context.

NLP Pipeline

Raw text must be preprocessed before ML models can use it:

  1. Text Cleaning — remove HTML tags, special characters, extra whitespace
  2. Tokenisation — split into tokens (words, subwords, or characters)
  3. Lowercasing — normalise case
  4. Stop Word Removal — remove common words (the, is, at) for bag-of-words approaches
  5. Stemming / Lemmatisation — reduce words to root form ("running" → "run")
  6. Vectorisation — convert text to numbers (TF-IDF, Word2Vec, BERT embeddings)

Text Representations

Bag of Words (BoW)

Counts word frequencies. Simple and fast but ignores word order and context.

TF-IDF

Term Frequency–Inverse Document Frequency. Weights terms by how unique they are across the corpus. Better than BoW for search and classification.

Word Embeddings (Word2Vec, GloVe)

Dense vector representations where semantically similar words are close in vector space. Famous property: king − man + woman ≈ queen.

Contextual Embeddings (BERT, GPT)

Unlike Word2Vec, contextual embeddings change based on surrounding words. "bank" near "river" gets a different vector than "bank" near "money".

Code Example: NLP Pipeline with spaCy

import spacy

# Load English model
nlp = spacy.load("en_core_web_sm")

text = "Apple is looking at buying U.K. startup Horizon for $1 billion."
doc = nlp(text)

# Tokenisation
print("Tokens:", [token.text for token in doc])

# Part-of-Speech Tagging
print("\nPOS Tags:")
for token in doc:
    print(f"  {token.text:15} → {token.pos_:8} ({token.dep_})")

# Named Entity Recognition
print("\nNamed Entities:")
for ent in doc.ents:
    print(f"  {ent.text:20} → {ent.label_}")
# Output:
#   Apple                → ORG
#   U.K.                 → GPE (geopolitical entity)
#   Horizon              → ORG
#   $1 billion           → MONEY

# Sentiment Analysis using transformers
from transformers import pipeline
sentiment = pipeline("sentiment-analysis")
reviews = [
    "This NLP tutorial is incredibly helpful!",
    "The explanation was confusing and unclear."
]
for r in reviews:
    result = sentiment(r)[0]
    print(f"{result['label']} ({result['score']:.2%}): {r}")
