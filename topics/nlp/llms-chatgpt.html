Large Language Models & ChatGPT

Large Language Models (LLMs) are massive neural networks — built on Transformer architecture — trained on hundreds of billions of words from the internet, books, and code. They represent the current frontier of AI, capable of reasoning, writing, coding, and conversation at near-human level.

🤖
What Makes an LLM "Large"?
Scale: GPT-3 = 175B parameters. GPT-4 ≈ 1T+ parameters. Llama 3.1 = up to 405B. Trained on terabytes of text for weeks on thousands of GPUs. The "scaling laws" show that bigger models trained on more data = reliably better performance.

How LLMs Work

Pre-training: Next Token Prediction

LLMs learn by predicting the next word/token in a sequence — called autoregressive language modelling. Given "The cat sat on the ___", predict "mat". Repeat this for hundreds of billions of examples and the model learns grammar, facts, reasoning, and code from the pattern alone.

Fine-tuning: Instruction Following

Raw pre-trained models generate text but don't follow instructions well. Fine-tuning on instruction-response pairs (e.g., supervised fine-tuning on Q&A data) teaches the model to be helpful.

RLHF: Reinforcement Learning from Human Feedback

The secret behind ChatGPT's conversational ability. Three steps:

  1. Collect human preferences — show raters pairs of model outputs, ask which is better
  2. Train a Reward Model — learns to predict human preference scores
  3. Fine-tune LLM with PPO — use RL to maximise the reward model's score

Result: Model learns to be helpful, harmless, and honest — not just to predict text.

Prompt Engineering

Getting good output from LLMs is a skill. Key techniques:

from openai import OpenAI
client = OpenAI()

# --- Zero-shot prompting ---
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Explain backpropagation in simple terms."}]
)
print(response.choices[0].message.content)

# --- Few-shot prompting (show examples in the prompt) ---
few_shot_prompt = """
Classify the sentiment of these reviews:
Review: "Amazing product, works perfectly!" → POSITIVE
Review: "Terrible quality, broke in a day." → NEGATIVE
Review: "It's okay, does the job." → NEUTRAL

Review: "Best purchase I've made this year!" → """

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": few_shot_prompt}]
)
print(response.choices[0].message.content)  # POSITIVE

# --- Chain of Thought (CoT) prompting ---
cot_prompt = """
Solve step by step:
If a store sells 150 apples on Monday and 30% more on Tuesday,
how many total apples were sold across both days?
Let's think step by step:"""

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": cot_prompt}]
)
print(response.choices[0].message.content)
# Step 1: Tuesday = 150 × 1.3 = 195 apples
# Step 2: Total = 150 + 195 = 345 apples

LLM Capabilities & Limitations

Capability ✅Limitation ⚠️
Text generation, summarisationHallucination — confidently stating false facts
Code generation and debuggingKnowledge cutoff — no real-time information
Translation, question answeringNo persistent memory across conversations
Few-shot learningCan be biased by training data
Reasoning and analysisSensitive to prompt phrasing
Creative writingCannot verify its own outputs reliably

RAG: Retrieval-Augmented Generation

The most practical solution to LLM hallucination and knowledge cutoffs: retrieve relevant documents from a database and include them in the prompt context. The LLM then generates answers grounded in verified sources.

⚠️
Hallucination Warning
LLMs can generate plausible-sounding but completely false information — called "hallucination." Never use LLM output as ground truth for medical, legal, or safety-critical decisions without expert verification.
💡
Career Insight
LLM engineering (prompt engineering, fine-tuning, RAG systems, evaluation) is one of the fastest-growing AI career paths. Understanding how LLMs work — not just how to use them — is a significant competitive advantage.
