Reinforcement Learning

Reinforcement Learning (RL) is a learning paradigm where an agent learns to make decisions by interacting with an environment. It receives rewards for good actions and penalties for bad ones — learning through trial and error, just like how humans and animals learn.

🎮
Real-World Analogy
Teaching a dog to sit: say "sit" → dog sits → give treat (reward). Dog eventually learns that sitting after "sit" command leads to treats. RL works the same way — maximise cumulative rewards over time.

The RL Loop

🤖 Agent
→
Action (a)
🌍 Environment
→
State (s') + Reward (r)
🤖 Agent

Key Components

  • Agent — the learner/decision-maker (e.g., a robot, game-playing AI)
  • Environment — everything the agent interacts with (e.g., a game, a room)
  • State (s) — current situation of the agent in the environment
  • Action (a) — what the agent can do in a given state
  • Reward (r) — feedback signal: +1 for good, -1 for bad, 0 for neutral
  • Policy (π) — the strategy mapping states to actions: π(s) → a
  • Value Function V(s) — expected total future reward from state s
  • Q-Function Q(s,a) — expected total reward taking action a in state s

Q-Learning

Q-Learning is a model-free RL algorithm that learns the optimal action-selection policy by updating Q-values using the Bellman Equation:

📐
Bellman Equation
Q(s, a) ← Q(s, a) + α [r + γ · max Q(s', a') − Q(s, a)]

α = learning rate | γ = discount factor (how much future rewards matter) | s' = next state 
import numpy as np

# Simple Q-Learning on a grid world
# States: 0-5, Actions: 0=left, 1=right
# Goal: reach state 5, reward +100 when done

n_states  = 6
n_actions = 2
Q = np.zeros((n_states, n_actions))

alpha = 0.1   # learning rate
gamma = 0.9   # discount factor
epsilon = 0.1 # exploration rate

def get_reward(state, action):
    next_state = state + 1 if action == 1 else max(0, state - 1)
    reward = 100 if next_state == 5 else -1
    return next_state, reward

# Training loop
for episode in range(1000):
    state = 0
    for _ in range(50):  # max steps per episode
        # Epsilon-greedy action selection
        if np.random.random() < epsilon:
            action = np.random.randint(n_actions)  # explore
        else:
            action = np.argmax(Q[state])  # exploit

        next_state, reward = get_reward(state, action)

        # Q-value update (Bellman equation)
        Q[state, action] += alpha * (
            reward + gamma * np.max(Q[next_state]) - Q[state, action]
        )

        state = next_state
        if state == 5:
            break

print("Learned Q-table:")
print(Q)
print("\nOptimal policy:", ["right" if np.argmax(Q[s]) == 1 else "left" for s in range(n_states)])

Deep Reinforcement Learning

When state/action spaces are too large for a Q-table, we use a neural network to approximate the Q-function — called Deep Q-Network (DQN). This is how DeepMind's agents learned to play Atari games at superhuman level.

Famous RL Milestones

  • Atari Games (2013) — DQN learned 49 Atari games from raw pixels, surpassing human performance on many
  • AlphaGo (2016) — Defeated world Go champion Lee Sedol; Go has more positions than atoms in the universe
  • AlphaZero (2017) — Mastered Chess, Go, and Shogi from scratch in hours using only self-play
  • OpenAI Five (2019) — Beat professional Dota 2 teams in 5v5 games
  • ChatGPT RLHF (2022) — Used RL from Human Feedback to align LLMs with human preferences

Exploration vs Exploitation

⚖️
The Core Dilemma
Exploitation: Use what you know works (greedy). Risk: miss better options.
Exploration: Try new actions randomly. Risk: waste time on bad actions.

Solution: ε-greedy — explore with probability ε (e.g., 10%), exploit otherwise. Decay ε over time as agent learns more.
