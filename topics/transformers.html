Transformers & Attention Mechanism

⏱ 11 min read

The Transformer, introduced in "Attention Is All You Need" (Vaswani et al., Google, 2017), is the architecture that powers virtually every state-of-the-art NLP model today — BERT, GPT-4, Claude, Gemini, and more. It replaced RNNs by processing entire sequences in parallel using self-attention.

⚡
Why Transformers Beat RNNs
RNNs process tokens sequentially (slow, vanishing gradient). Transformers process ALL tokens simultaneously using attention — massive parallelism on GPUs, no gradient degradation over distance. Long-range dependencies become easy.

Self-Attention: The Core Idea

Self-attention allows each token to "look at" all other tokens in the sequence and decide which ones are most relevant to its own meaning.

Example: In "The animal didn't cross the street because it was too tired", which word does "it" refer to? Self-attention lets the model figure out that "it" → "animal" (not "street") by computing attention weights across all tokens.

Query, Key, Value (Q, K, V)

Each token is transformed into three vectors:

  • Query (Q) — "What am I looking for?"
  • Key (K) — "What do I represent / advertise?"
  • Value (V) — "What information do I actually carry?"
📐
Scaled Dot-Product Attention Formula
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V

QKᵀ = similarity scores between queries and keys | √d_k = scaling factor (prevents softmax saturation) | softmax = normalise to probabilities | · V = weighted sum of values

Multi-Head Attention

Instead of computing attention once, Transformers run attention h times in parallel with different learned projections (heads). Each head can focus on different relationship types — syntax, coreference, semantics simultaneously.

Transformer Architecture

ComponentRole
Token EmbeddingsConvert tokens to dense vectors
Positional EncodingAdd position information (Transformer has no recurrence, so position must be injected)
Multi-Head Self-AttentionAttend to all positions in the sequence simultaneously
Feed-Forward Network2-layer MLP applied to each position independently (adds non-linearity)
Layer NormalisationStabilise training, applied before each sub-layer
Residual ConnectionsSkip connections around each sub-layer to help gradient flow
Encoder StackN layers of attention + FFN — builds rich contextual representations (BERT uses this)
Decoder StackN layers with masked self-attention + cross-attention to encoder (GPT uses encoder-only with causal masking)

Code: Using BERT for Text Classification

from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

# Load pre-trained BERT fine-tuned for sentiment
model_name = "distilbert-base-uncased-finetuned-sst-2-english"
tokenizer  = AutoTokenizer.from_pretrained(model_name)
model      = AutoModelForSequenceClassification.from_pretrained(model_name)

texts = [
    "Transformers revolutionised NLP completely.",
    "This explanation was very hard to follow.",
]

# Tokenise (returns input_ids, attention_mask)
inputs = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")

# Inference (no gradient needed)
with torch.no_grad():
    outputs = model(**inputs)
    logits  = outputs.logits
    probs   = torch.softmax(logits, dim=-1)

labels = ["NEGATIVE", "POSITIVE"]
for text, prob in zip(texts, probs):
    pred = labels[prob.argmax()]
    conf = prob.max().item()
    print(f"{pred} ({conf:.2%}): {text}")

Positional Encoding

Since Transformers process all tokens simultaneously (unlike RNNs which see them sequentially), they have no inherent notion of position. Positional encoding adds position information to embeddings using sinusoidal functions:

import numpy as np

def positional_encoding(seq_len, d_model):
    PE = np.zeros((seq_len, d_model))
    for pos in range(seq_len):
        for i in range(0, d_model, 2):
            PE[pos, i]     = np.sin(pos / 10000 ** (2*i / d_model))
            PE[pos, i + 1] = np.cos(pos / 10000 ** (2*i / d_model))
    return PE

# Example: 10 tokens, 512-dim embeddings
PE = positional_encoding(seq_len=10, d_model=512)
print(f"PE shape: {PE.shape}")   # (10, 512)
# Each row = unique position signature added to token embedding

Key Insight
The Transformer's ability to scale (just add more layers, more heads, more parameters) is why we went from 110M parameters (BERT-base, 2018) to 1.8T parameters (GPT-4, 2023). Architecture scales cleanly with compute.
