Convolutional Neural Networks (CNNs)

⏱ 11 min read

A Convolutional Neural Network (CNN) is a specialised deep learning architecture designed to process grid-like data such as images. Rather than treating each pixel as an independent feature (like a fully connected network does), CNNs exploit the spatial structure of images by learning local patterns — edges, textures, and shapes — using filters that slide across the input.

🖼️
Why Not Just Use a Fully Connected Network?
A 224×224 RGB image has 150,528 pixels. A single fully connected layer with 1,000 neurons would need 150 million parameters — just for one layer. CNNs use parameter sharing (one filter applied everywhere) and local connectivity (neurons connect only to nearby pixels), reducing this to a few thousand parameters per layer while preserving spatial relationships.

The Convolution Operation

The core operation in a CNN is the convolution. A small matrix called a filter (or kernel) — typically 3×3 or 5×5 — slides across the input image one step at a time (controlled by the stride). At each position it computes the element-wise product with the underlying image region, then sums the results to produce a single output value.

The collection of output values across all positions forms a feature map (also called an activation map). Each filter learns to detect a specific local pattern: one filter may detect vertical edges, another detects horizontal edges, a third detects colour gradients, and so on.

  • Filter / Kernel — small learnable weight matrix; slides across the input to detect a specific feature
  • Feature Map — the output of applying one filter to the entire input; shows where that feature is detected
  • Stride — how many pixels the filter moves at each step; stride=1 means dense overlap, stride=2 halves spatial dimensions
  • Padding — adding zeros around the border of the input; "same" padding preserves spatial size, "valid" padding shrinks it
  • Depth / Channels — a conv layer applies many filters in parallel, producing one feature map per filter

Pooling Layers

After convolution and activation, a pooling layer reduces the spatial size of feature maps. This decreases computation, controls overfitting, and makes representations slightly translation-invariant (the network still recognises a cat even if it shifts a few pixels).

  • Max Pooling — takes the maximum value in each pooling window (e.g., 2×2). Preserves the strongest feature activation. Most common choice.
  • Average Pooling — takes the mean value in each window. Produces smoother representations; used in some architectures like GoogLeNet for global pooling before the classifier.
📏
Effect of 2×2 Max Pooling with Stride 2
Input: 28×28 feature map → Output: 14×14 feature map. Spatial dimensions halved, number of parameters and compute roughly quartered, while retaining the dominant features detected by convolution.

CNN Architecture Flow

A typical CNN stacks these operations in sequence before a final classifier:

  1. Conv Layer — apply N filters → N feature maps
  2. ReLU Activation — introduce non-linearity; set negatives to zero
  3. Pooling Layer — downsample spatial dimensions
  4. (Repeat Conv → ReLU → Pool blocks as needed)
  5. Flatten — convert 3D feature maps to a 1D vector
  6. Dense (Fully Connected) Layers — combine learned features for final prediction
  7. Softmax Output — class probabilities

Famous CNN Architectures

Architecture Year Key Innovation Depth
LeNet-5 1998 First practical CNN; digit recognition for cheques 5 layers
AlexNet 2012 Won ImageNet by large margin; introduced ReLU & Dropout at scale 8 layers
VGG16 2014 Showed depth matters; uniform 3×3 conv blocks throughout 16 layers
ResNet-50 2015 Residual/skip connections solve vanishing gradient in very deep nets 50–152 layers
EfficientNet 2019 Compound scaling of depth/width/resolution; state-of-the-art efficiency Variable (B0–B7)

Keras CIFAR-10 Example

CIFAR-10 contains 60,000 colour images (32×32 px) across 10 classes (airplane, car, bird, cat, etc.). Here is a complete CNN that achieves ~75–80% accuracy:

import tensorflow as tf
from tensorflow import keras

# Load and normalise data
(x_train, y_train), (x_test, y_test) = keras.datasets.cifar10.load_data()
x_train = x_train.astype("float32") / 255.0
x_test  = x_test.astype("float32")  / 255.0

# Build CNN
model = keras.Sequential([
    # Block 1
    keras.layers.Conv2D(32, (3, 3), activation="relu", padding="same",
                        input_shape=(32, 32, 3)),
    keras.layers.Conv2D(32, (3, 3), activation="relu", padding="same"),
    keras.layers.MaxPooling2D(2, 2),
    keras.layers.Dropout(0.25),

    # Block 2
    keras.layers.Conv2D(64, (3, 3), activation="relu", padding="same"),
    keras.layers.Conv2D(64, (3, 3), activation="relu", padding="same"),
    keras.layers.MaxPooling2D(2, 2),
    keras.layers.Dropout(0.25),

    # Classifier
    keras.layers.Flatten(),
    keras.layers.Dense(512, activation="relu"),
    keras.layers.Dropout(0.5),
    keras.layers.Dense(10, activation="softmax")   # 10 CIFAR classes
])

model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=1e-3),
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)

model.summary()

history = model.fit(
    x_train, y_train,
    epochs=30,
    batch_size=64,
    validation_split=0.1
)

test_loss, test_acc = model.evaluate(x_test, y_test, verbose=0)
print(f"Test accuracy: {test_acc:.4f}")   # ~0.78

Transfer Learning

Transfer learning is one of the most powerful techniques in computer vision. Instead of training a CNN from scratch (which requires millions of images and days of compute), you load a model already pretrained on a large dataset like ImageNet (1.2M images, 1,000 classes), freeze its convolutional base, and only train a new classifier head on your smaller dataset.

💡
Transfer Learning in 5 Lines
base = keras.applications.EfficientNetB0(weights="imagenet", include_top=False, input_shape=(224,224,3))
base.trainable = False
x = keras.layers.GlobalAveragePooling2D()(base.output)
out = keras.layers.Dense(num_classes, activation="softmax")(x)
model = keras.Model(base.input, out)

The pretrained filters (edges, textures, shapes) are reused. Only the final dense layer is trained — achieving high accuracy with just a few hundred images.
