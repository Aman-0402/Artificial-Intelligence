Neural Networks

⏱ 12 min read

A neural network is a computational model inspired by the structure of biological brains. It consists of layers of interconnected neurons (nodes) that transform input data into useful predictions or representations. Neural networks are the backbone of modern deep learning — powering image recognition, language models, and much more.

🧠
Biological Inspiration
Just as a biological neuron fires when its inputs exceed a threshold, an artificial neuron computes a weighted sum of inputs, adds a bias, then passes the result through an activation function to decide whether (and how strongly) to "fire."

What is a Neuron?

Each artificial neuron performs a simple computation:

  1. Receive inputs x₁, x₂, …, xₙ
  2. Multiply each input by its learned weight: w₁x₁ + w₂x₂ + … + wₙxₙ
  3. Add a bias term b
  4. Pass the result through an activation function f
  5. Output: y = f(w · x + b)

Thousands of such neurons, wired together in layers, can learn extraordinarily complex patterns from raw data.

Layers of a Neural Network

Every feedforward neural network has three types of layers:

  • Input Layer — receives raw features (e.g., pixel values, numerical columns). One neuron per feature. No computation happens here.
  • Hidden Layers — one or more intermediate layers that learn progressively abstract representations. A network with 2+ hidden layers is called a deep neural network.
  • Output Layer — produces the final prediction. Size depends on the task: 1 neuron for binary classification, N neurons for N-class classification, 1 neuron for regression.
📐
Depth vs Width
Depth (more hidden layers) lets the network learn hierarchical features — edges → shapes → objects. Width (more neurons per layer) increases capacity within each level of abstraction. Modern architectures balance both.

Activation Functions

Activation functions introduce non-linearity. Without them, stacking layers would be equivalent to a single linear transformation — the network could not learn complex patterns.

Activation Formula Output Range Best Used In
Sigmoid 1 / (1 + e⁻ˣ) (0, 1) Binary classification output layer
Tanh (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ) (−1, 1) Hidden layers (zero-centred)
ReLU max(0, x) [0, ∞) Hidden layers — default choice
Leaky ReLU max(0.01x, x) (−∞, ∞) Hidden layers (fixes dead ReLU)
Softmax eˣⁱ / Σ eˣʲ (0, 1), sums to 1 Multi-class classification output

Forward Propagation

Forward propagation is how a neural network makes a prediction. Data flows from the input layer, through each hidden layer (each applying its weights, biases, and activation), until it reaches the output layer and produces a prediction.

For a single layer: A = f(W · X + b), where W is the weight matrix, X is the input, b is bias, and f is the activation function. This is repeated for every layer in sequence.

Backpropagation & Gradient Descent

Backpropagation is the algorithm used to train neural networks. After a forward pass produces a prediction, a loss function (e.g., cross-entropy, MSE) measures how wrong the prediction is. Backprop then computes the gradient of the loss with respect to every weight in the network using the chain rule of calculus, propagating error signals backwards from output to input.

Gradient descent uses those gradients to nudge each weight in the direction that reduces the loss:

📉
Weight Update Rule
w ← w − η · (∂L/∂w)

η = learning rate (step size) | ∂L/∂w = gradient of loss w.r.t. weight.
In practice, Adam (adaptive moment estimation) is used instead of vanilla gradient descent — it adjusts the learning rate per parameter automatically.

Training Loop in One Sentence

Repeat: forward pass → compute loss → backprop gradients → update weights — until the loss converges.

Keras MNIST Example

The MNIST dataset contains 70,000 handwritten digit images (28×28 pixels). Below is a complete neural network that achieves ~98% accuracy:

import tensorflow as tf
from tensorflow import keras

# Load and preprocess data
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()
x_train = x_train.reshape(-1, 784).astype("float32") / 255.0
x_test  = x_test.reshape(-1, 784).astype("float32") / 255.0

# Build the model
model = keras.Sequential([
    keras.layers.Dense(256, activation="relu", input_shape=(784,)),
    keras.layers.Dropout(0.3),
    keras.layers.Dense(128, activation="relu"),
    keras.layers.Dropout(0.2),
    keras.layers.Dense(10, activation="softmax")   # 10 digit classes
])

model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"]
)

model.summary()

# Train
history = model.fit(
    x_train, y_train,
    epochs=15,
    batch_size=128,
    validation_split=0.1,
    verbose=1
)

# Evaluate
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=0)
print(f"Test accuracy: {test_acc:.4f}")   # ~0.9820

Common Training Problems & Fixes

Vanishing Gradient

In deep networks, gradients are multiplied through many layers during backprop. When activation functions like Sigmoid or Tanh are used, their derivatives are small (≤ 0.25), so gradients shrink exponentially as they travel backwards — early layers learn extremely slowly or not at all.

  • Fix 1: Use ReLU (derivative is 1 for positive inputs — gradients pass unchanged)
  • Fix 2: Use Batch Normalisation to keep activations in a healthy range
  • Fix 3: Use residual/skip connections (ResNet) to provide gradient shortcuts
  • Fix 4: Careful weight initialisation (He init for ReLU, Glorot/Xavier for Tanh)

Dead ReLU Problem

A ReLU neuron outputs 0 for all negative inputs. If a neuron's weights push it into always receiving negative values, its gradient becomes permanently 0 — it stops learning entirely. This is the "dead ReLU" problem.

  • Fix 1: Use Leaky ReLU — allows a small negative slope (e.g., 0.01x) so gradients still flow
  • Fix 2: Use ELU or SELU variants with smooth negative regions
  • Fix 3: Lower the learning rate to prevent large weight updates that kill neurons
💡
Practical Tip
Start with ReLU activations, Adam optimiser, He weight initialisation, and Batch Normalisation. This combination works well for the vast majority of feedforward networks and avoids both vanishing gradients and dead neurons out of the box.
