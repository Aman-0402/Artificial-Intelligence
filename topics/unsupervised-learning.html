Unsupervised Learning

⏱ 8 min read

Unsupervised learning finds hidden patterns in unlabelled data. There are no correct answers provided — the algorithm discovers structure by itself. This is closer to how humans learn by observing the world without explicit instruction.

🔍
Key Difference from Supervised
No labels. No right answers. The model finds its own groupings, patterns, and representations from raw data. The challenge: evaluating quality without ground truth.

Main Categories

1. Clustering

Group similar data points together without knowing the groups in advance.

K-Means Clustering

The most common clustering algorithm. Partitions n observations into k clusters where each observation belongs to the cluster with the nearest mean (centroid).

from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs
import numpy as np

# Generate synthetic data: 300 points, 4 clusters
X, _ = make_blobs(n_samples=300, centers=4, random_state=42)

# Fit K-Means (we specify k=4)
kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
kmeans.fit(X)

labels = kmeans.labels_        # cluster assignments for each point
centers = kmeans.cluster_centers_  # centroid coordinates

print(f"Cluster labels (first 10): {labels[:10]}")
print(f"Inertia (within-cluster SSE): {kmeans.inertia_:.2f}")

# Choosing k: Elbow method
inertias = []
for k in range(1, 10):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(X)
    inertias.append(km.inertia_)
# Plot inertias and look for the "elbow" — where improvement slows

DBSCAN — Density-Based Clustering

Groups points by density — can find arbitrary-shaped clusters and identify outliers as noise. Does not require specifying k upfront.

2. Dimensionality Reduction

Reduces the number of features while preserving important information. Used for visualisation, denoising, and feature extraction before supervised learning.

PCA — Principal Component Analysis

Finds directions (principal components) of maximum variance in the data. Projects data onto a lower-dimensional space along these directions.

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import load_digits

# Load digits dataset (1797 samples, 64 features → 8×8 images)
digits = load_digits()
X = digits.data

# Standardise features
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Reduce to 2D for visualisation
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)

print(f"Original shape: {X.shape}")          # (1797, 64)
print(f"Reduced shape:  {X_2d.shape}")       # (1797, 2)
print(f"Variance explained: {pca.explained_variance_ratio_.sum():.2%}")

# How many components to retain 95% variance?
pca_95 = PCA(n_components=0.95)
X_95 = pca_95.fit_transform(X_scaled)
print(f"Components for 95% variance: {pca_95.n_components_}")  # ~29

t-SNE & UMAP

Non-linear dimensionality reduction for visualisation only. Excellent at revealing cluster structure in 2D/3D. t-SNE is slower; UMAP is faster and preserves more global structure.

3. Anomaly Detection

Identifies data points that deviate significantly from the norm. Used in fraud detection, network intrusion detection, and quality control.

4. Association Rule Mining

Discovers relationships between variables. Classic example: market basket analysis — "customers who buy bread also tend to buy butter." Algorithm: Apriori, FP-Growth.

💡
Real-World Use Case
E-commerce platforms use K-Means clustering to segment millions of users into groups (e.g., "high-value frequent buyers", "bargain hunters", "window shoppers") without any labelling — then tailor marketing campaigns per cluster.
